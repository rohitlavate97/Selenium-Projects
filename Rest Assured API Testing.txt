                     WHAT IS A REST API
================================================================================

+--------------------+                                   +--------------------+
|                    |                                   |                    |
|       CLIENT       |                                   |       SERVER       |
|   (Browser / App)  |                                   |     (Backend)      |
|                    |                                   |                    |
+--------------------+                                   +--------------------+
          |                                                           |
          |                                                           |
          |   HTTP REQUEST                                           |
          |   ---------------------------------------------------->  |
          |                                                           |
          |   METHODS:                                               |
          |     • GET                                                 |
          |     • POST                                                |
          |     • PUT                                                 |
          |     • DELETE                                              |
          |                                                           |
          |   URL / ENDPOINTS                                        |
          |     • /surveys                                           |
          |     • /surveys/123                                       |
          |     • /surveys/123/resp                                  |
          |                                                           |
          |                                                           |
          |                           PROCESS REQUEST                 |

          |                                                           |
          |   JSON RESPONSE                                          |
          |   <----------------------------------------------------  |
          |                                                           |

+--------------------+                                   +--------------------+

REST API: Light weight protocols(Easy to build and maintain)
SOAP Services: So many conditons and restriction
Base URL or Endpoint: Address where API is hosted on the server

HTTP Methods used to communicate with Rest API's are:
 GET:   Used to extract information from the given server using a given URI, no payload/Body required(BODY is the containerPAYLOAD is the data inside the container)
        To input data in GET, use Query parameter
 POST:  A POST Request is used to send data to the server using Form parameters/Body payload
 PUT:   Updating/Replace all current representation of the target resource with the uploaded content
 DELETE:Remove all current Representations of the target resource given by a URI
 
-Resources represent API/Collection which can be accessed from the server 
  www.google.com/maps  --> www.google.com is server(Place where all your api's stored i.e Basic URI) + /maps is resource(which help to tie up to map api)
  There are few more details which are optional, depends upon how api is designed.
  
-Path Parameter--> Are variable parts of a URL path. They are typically used to point specific resource within collection, such as a user identified by ID
                   eg: https://www.google.com/images/112233
				       https://www.google.com/search?q=rest
-Query Parameter-->Used to sort/filter the resources, identified with '?'
                   eg: https://amazon.com/orders?sort_by=2/20/2020   --->sort_by=2/20/2020 this is the query
-Header/cookies-->Headers represent the meta-data associated with API request and response.(Additional details to process the request)
                  eg: Autorization details
				  
End Point Request URL constructed as below--> Base_URL/Resource/(Query_params/Path_params)

--Given–When–Then is a simple way to write test cases in human-readable steps.
✅ Given: This method accepts all the input we need to submit for API.
Precondition / Setup
What is already true before the action?
Example: Base URI set, headers set, payload prepared, user is logged in.
✅ When: This method will hit and submit API
Action
What you do / what request you send.
Example: Send a POST request to add a place.

✅ Then: This method validate the response
Expected Result / Verification
What you validate after action.
Example: Status code is 200, response has place_id, message is OK.

Note: User JSON to Java String Converter for body(https://dadroit.com/json-to-string/)

import io.restassured.RestAssured;

import static org.hamcrest.CoreMatchers.equalTo;

public class ParsingJson {

	public static void main(String[] args) {
		RestAssured.baseURI = "https://rahulshettyacademy.com";
		String response = given()
		   .queryParam("key","qaclick23")
		   .header("Content-Type","application/json")
		   .body("{\n  \"location\": {\n    \"lat\": -33.8669710,\n    \"lng\": 151.1958750\n  },\n  \"accuracy\": 50,\n  \"name\": \"Test Place 1\",\n  \"phone_number\": \"(02) 1234 5678\",\n  \"address\": \"100 Fictional Street, Test City\",\n  \"types\": [\"restaurant\", \"bar\"],\n  \"website\": \"http://testplace.example.com\",\n  \"language\": \"en-AU\"\n}")
		.when()
		   .post("/maps/api/place/add/json")
		.then()
		   .log().all().assertThat().statusCode(200).header("Server","Apache/2.4.52 (Ubuntu)").body("status",equalTo("OK"))
		   .extract().response().asString();
		
		System.out.println("The Response is :"+response);
		
		//If we want to extract place_id, use JsonPath class-->String as input,converts to Json
		JsonPath js = new JsonPath(response);
		//js.getString(path);    --->If we provide path it will directly go to json and extract data
		String place_id = js.getString("place_id");
		System.out.println("The PlaceID is :"+place_id);
		
		String updateResponse = given()
		  .queryParam("key","qaclick23")
		  .header("Content-Type","application/json")
		  .body("{\n  \"place_id\": \"{{place_id}}\",\n  \"address\": \"70 Summer walk, USA\",\n  \"key\": \"qaclick23\"\n}")
		.when()
		  .put("/maps/api/place/update/json")
		.then()
		.assertThat().statusCode(200).body("msg", equalTo("Address successfully updated")).extract().response().asString();
		
		System.out.println(updateResponse);
		
		String getResponse = given()
		   .queryParam("key", "qaclick23")
		   .queryParam("place_id",place_id)
		   //.header("Content-Type","application/json")
		.when()
		   .get("/maps/api/place/get/json")
		.then()
		   .assertThat().statusCode(200).body("name", equalTo("Test Place 1")).extract().response().asString();
		
		System.out.println(getResponse);
		
        String delResponse = given()
		   .queryParam("key","qaclick23")

		   .body("{\n" +
			          "  \"place_id\": \"" + place_id + "\"\n" +

package com.alchemist;
